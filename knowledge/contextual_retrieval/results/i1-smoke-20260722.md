tests whether the sealed I1 configuration is eligible to scale to the complete
I1 panel; it is not a formal method-effectiveness conclusion. No Agent, RAGAS
evaluator, or Judge was initialized.

The generated raw data, Context cache, database, request records, and service
logs are intentionally not committed. This report preserves only aggregate,
sanitized evidence.
